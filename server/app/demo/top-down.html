Real-time Demo

4-way scroller. Move with WASD or arrow keys. Walk over a gem to collect it. Gems are item-state — updates spawn them, collections collect them. Character state is schema-declared: state: {position, health, name, color}, and score is server-authoritative — the server increments it on collection, this client never sends it. No timers anywhere: movement is keydown/keyup + requestAnimationFrame, disconnect is enforced by the server on the next packet (see below).

Disconnect rule: the server stores last_seen per client and disconnectionTime from your config (default 60s). On every inbound packet from any client it sweeps expired clients and evicts them with reason: "timeout". There is no timer loop. If nobody sends a packet, an idle client stays listed until the next packet arrives — that is the event-driven tradeoff. Your own late packet is rejected (403 disconnected: timeout) instead of reviving you. Keep-alive is just another packet: this demo sends character-state while moving and /heartbeat from the rAF loop when idle.
